# 全界面重构：清楚地选线，顺手地检测

## 授权、依据与方向

2026-11-18 用户明确要求真正的大重构，可重做导航、工作台及全部功能的界面组织；由当前代理自行决定，焕然一新、有辨识度、符合人的习惯，不能漏掉项目记忆中的能力。它覆盖旧分工中的 UI 决策限制，但不意味着自动修改探针规则、生产数据或运行版。

开工已读 Obsidian 项目总览的规划、经验、接续，Decisions 的 UI 决策，以及《线路观测台-研究与设计》的业务模型与六页构图；结合仓库 PROJECT_MEMORY L-001～L-016、现有 Vue 及 version-consistency 核能力。历史原型不是本轮验收结果。

首轮纸白/青绿、顶部导航、大标题加表格草稿被用户明确否定为难用、通用 AI 模板。它没有被认可，不能作为视觉基线继续扩展。重新阅读到既有原话：“给我们这个项目定制一套属于我们这个项目的 UI，而不是一个公共的模板……深度定制集成。”本轮继续从选节点、判断差异、配置检测和读依据的真实动作构图；仅改变配色、圆角、导航方位或加口号不算完成。

## 本轮源码落地

- 导航：线路、为你选线、订阅、监测、记录；偏好与数据使用文字工具入口。导航滚动时保留，任务条继续显示实际执行、保存失败与报告入口，命令查找仍可用。
- 工作台：来源状态常驻；节点、四站实际采样、下载、服务分组和纯净度在同一行对照。默认全宽列表，点击节点查看详情；小于 1440px 使用现有可聚焦的HTML dialog，宽窗口用原可调侧栏。跨筛选选择及比较保持；已选操作栏常驻窗口底部。检查器的跳转目录保留全部记录，延迟图按容器宽度绘制，不拉扁文字。
- 账户：机场索引配独立账户账单，原更新、仅用量刷新、编辑、Verge 与维护动作保留。没有到期日时显示未知，不能因有配额就写长期有效。
- 选线：用途索引配候选及其依据，不再四张并列评分卡。候选算法、历史配置边界、导出与回到工作台保持。
- 监测：节点任务、自动精选、定期采样三种入口；后两者保留挂载，切换不丢未保存表单。任务与预算状态使用原 API；状态读取失败不显示为已停止。
- 记录：左侧批次目录、右侧明细，窄窗口可返回目录。同名节点明确当前账户名称（提示为当前归属，不伪装历史快照名称），原同条件对比、原始历史、报告及导出接线保留。
- 偏好与数据：七类设置索引，切换保留修改，保存验证出错时回到对应类别；数据文件清单与备份操作并列，原有确认及迁移限制不变。
- 检测配置：项目/参数与本次范围/用量分开摆放；预设仅改延迟参数和轮数、保留下载/解锁/信誉；服务正反地区规则、完整生产目录、模型风险提醒和预算计算保持。开发预览只模拟七项服务，不代表生产目录缩减。
