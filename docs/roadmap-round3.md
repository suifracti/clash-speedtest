## 工作方式（每次开工必读）

先核用户当前目标、相关进度、已有实现及 [项目记忆](PROJECT_MEMORY.md)。个人工具保持简单，目标是正确可用、用户能感知；必要相关修复在授权内主动处理，不增加无依据的防护平台。验证按真实风险取最小充分证据，不设置测试/实现行数比，不规定修两次就强制重写，不为文档运行全部业务检查。

执行与核验按 AGENTS；先检查工作树再 fetch，不能盲目 pull。当前版本、生产数据、付费/实网请求和安装权限分别处理。缺接口标暂无数据来源，旧证据不冒充新验收。过程记可观察证据与关键取舍，不记录模型内部思维。

## 后端范围

### B1 数据正确性

1. SQLite 的 foreign_keys/busy_timeout/synchronous 应按连接生效：原方案比较 DSN pragma 与写连接/读池安排；孤儿数据先只读报告，不自动修生产库。
2. 历史清理需事务与错误上报，处理已终止但 finished_at 为空的记录，保留进行中的记录。
3. 用量网络抓取移出长时间持有的 profile 写锁，取消有明确收尾；不要让等待网络阻塞无关状态。

### B2 用量检测

接受小数/科学计数/重复字段；缺 upload 或 download 保留未知而非丢掉全部用量。缺有效用量头时备用 UA 只补头信息，不覆盖原节点内容。单订阅可设 UA；单账户“只刷新用量”与“更新节点”分开，复用现有抓取，不额外堆一套保护链路。

### B3 前端所需接口

监测 next_run_at、数据页 schema_version/last_backup_at、同条件上一条下载/服务记录。匹配与缺失语义要明确，不能以任意旧记录冒充同条件比较；前端对应监测卡片、数据页与记录页联动。具体已实现字段和接口看进度页及当前源码。

### B4 稳定性（按前述降级范围）

主要检测、刷新、用量、调度 worker 的必要 panic 收尾；Antigravity 登录去重；HTTP ReadHeaderTimeout 与已有客户端超时。可取消路径根据实际缺陷处理，不全仓替换 context，也不泛化为所有 goroutine 都需新包装。

### B5 隐私（按前述降级范围）

先补 RedactURL 对路径 token 的脱敏。URL 访问控制、远程密码比较和失败限速是当时讨论项，未获新范围授权不自动实施；本页不宣称它们当前有缺陷或已经解决。

### B6 整理（延后项保留）

原候选包括删除无用 gui/server.go、gui/manager.go，大文件拆分，真实历史自动保留/WAL checkpoint，测试命名整理和用注入时钟替换 sleep。只有前述明确选中的范围与后来实际授权才执行；不因出现在路线里自动删除文件或清理数据库。

## 前端范围

### F1 工程健康

CI 修复；CSS 按页面收尾、workspace 职责拆分、按页懒加载与表格虚拟滚动属于原提案。后四项按历史取舍延后；复核实际卡顿和已有实现后再决定，不以旧文件大小重开重构。

### F2 体验

机场侧栏搜索/折叠及最近测量健康提示；空状态区分无节点与被筛选隐藏；检测摘要显示测量时间；同条件记录比较、下次监测时间、数据库版本/最近备份信息。保留缺数据/未知语义，不把入口存在当数据正确。

### F3 已选功能范围

1. 订阅变化：前后两版节点比较新增/下线/改名，台账及来源带能查看名单。
2. 体检：按已有历史展示近 30 天按轮次可用率、失败类型、延迟及用量/用户本地价格构成的成本；原始条件不足时说明，慢了再评估必要汇总接口。
3. 推荐：按流媒体/AI/下载/日常给有时间、站点和次数依据的候选；证据不足明确说明。复用既有推荐和 exportSelection，不假定存在代码就能直接接前端。
4. macOS 通知：大面积失败、低余额/临近到期提醒，阈值在偏好、默认关闭；实际桌面绑定、设置及去重分别核对，不因路线存在自动开启通知或监测。

## Clash Verge 订阅导入与同步（2026-11-11）

目标是在账户页读取本机 Verge 的 remote 订阅及已保存节点，首次可新建机场或关联既有账户，后续按稳定 UID 同步链接变化。用户点击时同步，保留 CST 账户 ID 与已有历史连续性口径。

实现复用现有订阅刷新提交流程，将本机缓存作为 prepared fetch，保留节点变化、失败清除和用量快照；只提取代理节点，不导入 Verge 根设置。前端只接收脱敏来源摘要，首次只对唯一完整 URL 匹配建议关联，名字相同不自动合并。

验证覆盖本机索引解析、改链接后仍更新原账户及失败保留旧缓存、账户选择交互；实机只读核对订阅清单，功能验证使用临时数据。交付沿用统一 Mac 构建入口及既有记录落点。

## 执行与验证边界

原计划中的 F/B 字母是范围标识，不固定永久执行模型。只验证实际变化，使用本地服务与临时/脱敏数据；无对应许可不发真实节点检测、不动原数据根。真实 Mac 候选按 AGENTS 的统一构建入口，文档不打包，换运行版核对应授权。历史计划的全量测试矩阵不作为每次小改的固定工作量。

交付记录具体变化、证据、未测范围及必要下一步；重要经验当下进入项目记忆。当前进度只在原进度页维护，Vault 保留私人体验和长期决定。
