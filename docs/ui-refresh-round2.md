# 界面焕新第二轮（2026-10-20，前端）

基线 `e792836`。已知失败 6 个（`plan-queue-interactions` 5 个、`legacy-target-visibility` 1 个），本轮没有新增。

## 改了什么
- **设计系统**：`frontend/src/design/tokens.css`（`--cst-*`，浅/深色）是唯一的颜色、字体、圆角来源。旧变量（`--canvas`、`--surface`、`--hd-*` 等）单向映射到它。`base.css` 统一按钮、徽标、提示、弹窗和检测配置/队列的样式，`shell.css` 负责应用外壳。
- **外壳**：左侧栏放页面、机场快捷筛选和轻量任务区（只说三件事：在做什么、已处理多少/总数、有没有未保存或出错的项），底部是工具入口和“本地服务已连接”。窗口窄于 900px 时收成图标栏，窄于 640px 时变成底部标签栏。
- **弹窗焦点**：打开后焦点进入正文，Tab 只在弹窗内循环，Esc 关闭，关闭后焦点回到触发处。
- **⌘K**：可搜索页面、机场和节点。选中节点只在工作台检查器里查看，不勾选、不改筛选。已被筛掉的节点改用详情弹窗打开。
- **工作台**：
  - 工具条吸顶。
  - 检查器宽度可以拖动，也可以用 ←/→ 调整，宽度会记住。
  - “比较已选”在检查器位置就地展开。2 个节点并排显示；3 个及以上时比较区变宽，节点表收窄。按 Esc 或“退出比较”后恢复原来的滚动位置。
  - 来源带显示所查看账户今天、昨天、前天的用量。
- **检测配置**：按“范围 → 项目 → 参数 → 预算确认”排列。预设有快速观察、四站检查、小范围复测三种，只改延迟参数和轮数，不会取消已勾的其他项；之后再改任何参数就显示“自定义”。预算分开写：延迟算计划采样，服务/IP 算计划观察，下载算最多读取量，模型类额度单独提示。
- **队列**：每项一行，执行、结果、保存分成三列。用“已处理 x/总数”表示进度。启动尚未确认时不画进度条。
- **机场与账户**：账户台账每行显示套餐用量条、到期倒计时、今天/昨天/前天用量和 14 天小柱图。读不到的天显示“未记录/未知”，柱图画成斜纹，从不显示为 0。从公告里解析出的数值标注“公告识别”。
- **检测记录**：按天分组的时间线，选中一轮后在右侧打开记录单。“和上次比”（只做延迟批次）找同一节点、同一目标最近一次有采样的记录，不跳过最近的失败。只有方法和出口证据都一致时才比数值，条件不同就并排列出原始值。
- **持续监测**：每个任务有 24 小时离散时间带。空白表示没有采样；斜纹表示这段没有读到。任务列表刷新失败时，任务不再显示绿色“监测中”。
- **设置/数据**：每组设置标出生效时机。数据页把数据库版本和最近备份标为“暂无数据来源”。
