## Statistical contract and remaining boundaries

Success rate uses eligible recorded samples, excluding cancellation, not_executed, local/config/request/budget blocks and target 429. Percentiles use only valid successful RTT/TTFB or manual latency values; failed and excluded samples do not create zero latency. Non-latency probe percentiles remain unmeasured. Structured monitoring execution status / HTTP status are read from recorded metadata; no condition evidence is fabricated.

Group identity is recorded profile + node identity (missing identity isolates by recorded node key) + config revision + target + probe + tier + condition. Monitor DTOs lack method/version, address family/source and physical egress proof: monitor statistics always show unknown conditions and no same-condition ranking. Manual latency groups expose recorded method/path evidence and remain unknown when incomplete. No cross-group quality ranking is implemented.

Coverage describes the loaded records' earliest/latest timestamps, span and UTC dates. Monitoring groups count recorded run_id; manual latency groups count attempt_id, explicitly labeled rounds/attempts. One multi-site attempt remains one attempt per group and never proves cross-day stability. Missing run IDs remain unknown. Raw drilldown includes only currently loaded same-run evidence and does not assert full run completeness.

Cursor completeness refers only to the requested sample window; loaded-count summaries are explicit, failed reads remain incomplete, and facet truncation is separately reported. Current airport attribution is a label from current subscription metadata; historical airport membership is unrecorded. Nodes without stable historical identity, historical airport attribution, monitor path comparability, full-run backend detail and real long-running monitoring acceptance remain outside this frontend slice.
